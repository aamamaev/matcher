# Метчер товара в ТН ВЭД ЕАЭС

Прототип превращает карточку товара в топ-3 кода ТН ВЭД. Это черновик гипотезы: перед декларированием код сверяет брокер.

Ссылку открывает headless Chrome с теми же заголовками, что парсер Кинопоиска. Сейчас так читаются карточки Яндекс Маркета (`market.yandex.ru/card/…`) и AliExpress (`aliexpress.ru/item/…`). Wildberries и Ozon останавливают этот браузер антиботом, для них название вставляется вручную. Текст кодируется моделью `multilingual-e5-small`, Qdrant ищет близкие коды. Если в `.env` задан `LLM_API_KEY`, модель заново выбирает три кода только из найденного списка.

## Запуск

```bash
cd tn_ved
cp .env.example .env
npm run setup
npm run qdrant
npm run index
npm run dev
```

Интерфейс: http://127.0.0.1:5173

`npm run qdrant` поднимает контейнер, если Docker уже запущен. Иначе на macOS скачивает локальный бинарник Qdrant 1.20 и слушает порт 6333.

Первый `npm run index` скачивает выгрузку ФНС, английские описания HS6 и модель эмбеддингов, затем кладёт в Qdrant около 13 тысяч действующих 10-значных кодов. Это занимает несколько минут.

## Данные

Готового открытого набора «карточка маркетплейса → 10 знаков ТН ВЭД ЕАЭС» нет.

В индекс входят:

- действующие коды из архива ФНС [`tnved.zip`](https://data.nalog.ru/files/tnved/tnved.zip) (страница справочника: [nalog.gov.ru](https://www.nalog.gov.ru/rn77/program/5961290/)). Берутся строки без даты окончания либо с датой окончания не раньше сегодняшнего дня;
- английские названия субпозиций HS6 из [datasets/harmonized-system](https://github.com/datasets/harmonized-system). Первые шесть знаков общие с ЕАЭС, знаки 7–10 нет. Они нужны, потому что в файле ФНС промежуточный текст часто схлопнут, и лист называется «прочие»;
- `backend/data/examples.json`: короткие карточки, у которых действующий лист или шестизначная субпозиция прямо называет товар.

Не входят и не являются золотой разметкой ЕАЭС:

- [AIDC-AI/HSCodeComp](https://huggingface.co/datasets/AIDC-AI/HSCodeComp) — 632 экспертные e-commerce карточки и 10-значный код, но национальный хвост не евразийский;
- решения US CBP CROSS, например [flexifyai/cross_rulings_hts_dataset_for_tariffs](https://huggingface.co/datasets/flexifyai/cross_rulings_hts_dataset_for_tariffs);
- платные базы деклараций. Заявленный в декларации код — это наблюдение, не проверенная метка.

Переранжирование необязательно. Без ключа ответ — это топ-3 векторного поиска.
